# AEME 尺寸链计算工具

面向机械设计与装配公差分析的离线尺寸链计算工作台。通过输入组成环的基本尺寸、增减方向与上下偏差，实时查看封闭环的极值范围、统计范围和目标规格裕量，并预览公差反算方案。

应用使用中文界面，构建产物为一个自包含的 HTML 文件。下载 `尺寸链计算工具.html` 后，可在 Mac 或 Windows 的现代浏览器中直接打开；日常计算不需要安装 Node.js、启动服务或连接网络。

维护者已确认应用通过 Mac 和 Windows 系统验证（验证记录于 2026-10-12 更新）。

## 功能

| 功能 | 说明 |
| --- | --- |
| 组成环建模 | 支持 1–25 个组成环，输入基本尺寸、增环/减环、上偏差 ES、下偏差 EI、对称公差、分布类型、描述和备注。 |
| 封闭环计算 | 分别展示极值法与概率法的计算上下限、公差全宽，以及相对目标下限 LSL、上限 USL 的裕量。 |
| 统计模型 | 支持正态、三角、均匀、瑞利及内/外尺寸偏态的表列分布系数，提供置信水平预设与手动 k₀。 |
| 质量估算 | 在适用的正态模型或明确接受的等效正态假设下，估算合格率、上下侧超差 PPM、Cp 和 Cpk。 |
| 公差反算 | 支持极值或统计区间约束下的等公差、按现有公差比例分配；保留公差中点，跳过锁定环，复算候选方案，预览后应用，并支持继续编辑前撤销上次应用。 |
| 贡献分析 | 查看各环的极值宽度贡献和统计方差贡献，帮助定位主要影响环。 |
| 交互图形 | 提供尺寸链示意图、极值区间图和概率图，支持视图缩放、平移及目标规格线调整。 |
| 数据与报告 | 保存/打开项目 JSON、从 Excel 复制表格数据并粘贴、导出 CSV、浏览器打印报告或另存为 PDF。 |
| 本地暂存 | 尝试在当前浏览器自动暂存项目，提供恢复入口；重要项目应另存 JSON 文件。 |

内置三个参考样例：非对称端盖间隙、摇臂装配间隙和轴套定位尺寸。样例依据原始参考工作簿整理；第二、第三个样例按已启用的对称模式取 EI = −ES。工作簿文件不随项目发布。

质量分析页面可直接输入或拖动所选环的公差全宽，编辑范围为 0–10 mm；通过组成环表格或项目导入的大于 10 mm 的公差仍保留原值。

## 快速使用

1. 下载本仓库中的 `尺寸链计算工具.html`，在现代浏览器中打开。
2. 新建项目，或选择参考样例。逐行填写组成环的基本尺寸、方向、ES 和 EI；尺寸单位为 mm。
3. 输入封闭环目标 LSL/USL，查看实时计算结果和质量分析。
4. 如需反算，锁定不能修改的环，选择约束方法与分配策略，预览通过后再应用。
5. 使用“保存项目”导出 JSON；使用“导出完整结果 CSV”或“打印报告”保存结果。

在完整源码目录中打开 `src/shell.html` 也会自动转到根目录的应用。`src/shell.template.html` 是构建模板，包含待替换的占位符；修改模板后请运行 `npm run build`。

### 从 Excel 粘贴

复制以下五列后，点击“从 Excel 粘贴”。每行代表一个组成环，列之间用制表符分隔；可包含表头。

```text
环标识	基本尺寸	方向	上偏差	下偏差
A1	30	-	0	-0.1
A2	43	+	0.2	0.1
```

粘贴会替换当前组成环。请粘贴数值结果；空白公差须补全，固定尺寸请明确填写 `0`。应用不直接读取 `.xls`/`.xlsx` 文件，也不运行 Excel 公式或宏。

## 计算模型与适用范围

实现参考 GB/T 5847—2004《尺寸链 计算方法》的直线尺寸链公式，以及附录 A、C 的表列系数。原始标准 PDF 和参考工作簿不随源码发布。

对于第 i 个组成环，基本尺寸为 Lᵢ，方向 ξᵢ 为 +1 或 −1，公差全宽 Tᵢ = ESᵢ − EIᵢ，公差中点 Δᵢ = (ESᵢ + EIᵢ)/2。

```text
封闭环基本尺寸：L₀ = Σ ξᵢLᵢ
极值公差全宽：  T₀ = Σ Tᵢ
统计均值：      μ = Σ ξᵢ(Lᵢ + Δᵢ + eᵢTᵢ/2)
统计标准差：    σ = √Σ(ξᵢkᵢTᵢ/6)²
统计区间：      [μ − 3σ/k₀, μ + 3σ/k₀]
```

- 仅处理直线尺寸链，组成环方向为 ±1；不处理空间尺寸链、环间相关性或 CAD 模型导入。
- 极值范围以每个组成环的实际尺寸均在输入公差带内为前提；极值区间本身不代表概率分布。
- 统计计算假设各环相互独立；正态输入的公差全宽按 6σ 解释。
- 非正态分布的 e、k 用于均值和方差估算，不能还原实际分布。合格率、PPM、Cp/Cpk 须明确接受等效正态假设后才显示；曲线为等效正态示意。
- 含非正态输入且全链有效随机环少于 5 个时，统计区间需要选择手动 k₀ 或接受正态近似；有效随机环指所有公差全宽大于 0 的环。达到 5 个也不自动保证近似精度。手动 k₀ 不自动对应实际置信概率。
- 置信预设采用表内舍入系数，与精确正态积分概率可能有差异。
- 质量指标是基于设计参数的估算，不能替代实测过程能力、制造能力验证或产品验收。公差分配方案也不保证加工经济性最优。
- 示意图用于辅助理解尺寸链，不作为工程图纸；本版本不提供蒙特卡洛仿真。

## 本地数据

计算在浏览器中进行。构建产物没有运行时外部依赖，内容安全策略限制网络连接；应用不包含账户、云端存储或遥测功能。

项目 JSON、CSV 和打印报告通过浏览器在本地保存。JSON 文件及粘贴内容的输入上限为 1 MiB。自动暂存依赖浏览器存储，可能在移动 HTML 文件、更换浏览器或清理浏览器数据后失效；下载项目文件后，请确认已保存到需要的位置。

## 开发与验证

需要 Node.js 22 或更高版本及 npm。构建依赖为锁定版本的 esbuild；首次安装依赖通常需要联网。

```bash
npm ci
npm run build
npm test
```

`npm run build` 会在根目录生成 `尺寸链计算工具.html`。仓库保留此产物，方便直接使用；修改源码后请重新构建。

本地预览：

```bash
npm run dev
```

打开 `http://127.0.0.1:5173`。源码修改后执行 `npm run build` 并刷新；预览服务不会自动监听重建。

`npm test` 运行数值计算、公差反算、模型校验、项目读写和离线打包的自动化测试。`npm run check` 单独运行打包检查。`tests/browser-checks.js` 是供 Playwright 驱动调用的浏览器交互检查函数，未包含在 `npm test` 中。
