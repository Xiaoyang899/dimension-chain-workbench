计算依据与使用说明

依据与边界

计算公式参考 GB/T 5847—2004《尺寸链 计算方法》表 3，分布系数与置信预设参考资料性附录 A、C；原始标准文件不随本项目发布。仅支持直线尺寸链，ξ = +1 或 −1，不处理环间相关性。

极值与统计不是同一种承诺

极值法对每个有向尺寸区间取端点并求和。统计法使用 μ = Σξ(L + Δ + eT/2)、σ = √Σ(ξkT/6)²、T₀ = 6σ/k₀；T = ES − EI，Δ = (ES + EI)/2。偏态分布的均值可以偏离公差中心，极值计算不能随之移动。

L₀ = Σ ξᵢLᵢ
TOL = Σ |ξᵢ|Tᵢ
TOS = √Σ ξᵢ²kᵢ²Tᵢ² / k₀

分布系数

系数使用国标表值；k 不是“几倍 σ”，e 不是三阶偏度。全部随机环为正态时按正态模型计算；非正态组合只绘等效正态示意，不声称还原真实分布。含非正态输入且全链有效随机环（公差全宽大于 0）少于 5 个时，附录 C 提供无统计参考数据时 k₀ = 1.1–1.3 的参考范围，而非真实合格率。

质量指标属于设计估算

合格率由额外的独立正态模型积分得到，Cp = (USL − LSL)/(6σ)，Cpk = min(USL − μ, μ − LSL)/(3σ)。这不是实测过程能力，也不是本国标直接给出的质量保证。正态分布具有无界尾部，曲线不截断到极值范围。

反算为什么会无解？

固定环已用尽预算、中心偏离目标，或偏态中心移动导致两侧约束冲突时，目标可能不可达。等宽/比例分配保留原公差中点，对候选方案复算后才允许应用；结果不代表加工经济性或制造能力最优。

与原 Excel 的差异

保留参考模板的输入与绘图用途，但修正取绝对值隐藏方向、非对称偏差分别 RSS 等问题；对称模式会明确设置 EI = −ES。间隙请作为明确组成环输入，不沿用将空白公差自动混入结果的 ST_gap 非标准公式。
